● I've redesigned the home page and both classifier pages, but I couldn't test
  them: Jekyll isn't installed on this machine, so I haven't seen them in a
  browser. Nothing is committed yet. I left pyproject.toml and uv.lock alone.

  Shared classifier widget — _includes/classifier.html
  Both classifier pages had copies of the same script, so they now use this one
  shared file:
  - Upload area: you can drag and drop an image or click to choose one, and only
    image files are accepted.
  - Preview: the uploaded image appears inside the upload area, and you can drop
    another image onto it to try again.
  - While it runs: a spinner and a "Classifying…" message show, with a note that
    the model may take a moment to wake up. Before, nothing happened until the
    result came back.
  - Errors: if the request fails, a message appears on the page instead of
    failing silently.
  - Results: the predicted label is shown large, with a bar for each class's
    confidence.
  - Speed: the page connects to the Hugging Face model once, when it loads,
    instead of on every upload.
  - Safety: labels are inserted as plain text, so a label can't inject HTML into
    the page. The Gradio client is now pinned to version 2.5.0 instead of
    whatever the CDN serves as latest.

  Project pages
  - project-panda-grizzly.html and project-6-or-7.html each have a one-line
    intro and then the widget.
  - On the 6-or-7 page, the two 700px notebook viewers are now folded into "Code
    for model creation" and "Code for production interface" sections you click
    to open. They only load when opened.

  Home page — index.md
  It replaces the "Linked above…" text with a card for each project: an emoji, a
  title and a short description, laid out in a grid that stacks on phones.

  To check it, push to GitHub Pages or run bundle exec jekyll serve locally,
  then upload an image on each page. If the results look wrong, the likeliest
  cause is the Gradio response. The bars assume the model returns per-class
  confidences; if it doesn't, the page shows just the label.
